Welcome to **Kirari**, a beautiful Hugo theme inspired by the Astro theme of the same name!

## Features

Kirari comes with many features out of the box:

- Clean and modern design
- Dark/Light/Auto theme switching
- Responsive layout
- Full-text search with Pagefind
- Table of Contents
- Categories and Tags
- Archive page
- Friends page
- Giscus/Waline comments support
- i18n support (English, Chinese, Japanese)

## Getting Started

To start using Kirari, simply clone the theme and configure your `hugo.toml`:

```toml
theme = "kirari"

[params]
  title = "My Blog"
  subtitle = "A blog powered by Kirari"
```
